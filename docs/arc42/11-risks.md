# Risks and technical debt

Remote acceptance may precede local acknowledgement. Receipt cache eviction, Jira indexing delay, concurrent external writers, or manual marker removal can cause duplicates. Kubernetes findings are currently coarse. Suppressions pause all delivery for that target. Supported provider behaviors and cloud permissions require deployment checks. A crash can leave temporary plan artifacts. No distributed locking, full historical database, daemon, auto closure, or per-field policy engine exists.
