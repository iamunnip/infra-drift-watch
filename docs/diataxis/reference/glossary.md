# Glossary

| Term | Meaning |
| --- | --- |
| Drift | Observed change relative to a baseline |
| Pending change | Intended configuration not deployed |
| Target | Stable deployment scope |
| Receipt | Local acknowledgement for one destination |
| Coverage | Successfully inspected scope |
| Incomplete | Scan cannot establish clean status |
| Resolution | Complete selected scope no longer contains detected drift; it is distinct from issue closure |
